# codePulse - Backend 

مشروع **codePulse  Backend** عبارة عن API لخدمة عرض الأخبار والقصص التقنية مع نظام تعليقات وتصويت.

## 📌 الميزات

- إدارة الأخبار والقصص (CRUD)
- التعليقات على القصص
- التصويت للأخبار
- مكتوب بـ TypeScript مع Express
- قاعدة بيانات SQLite خفيفة وسهلة الاستخدام

## 🛠️ التقنيات المستخدمة
- Node.js
- TypeScript
- Express
- SQLite
 المتطلبات
- Node.js >= 18.x
- npm >= 9.x
- SQLite
